Proje Hakkında

Bu proje, C# programlama diliyle geliştirilmiş bir ATM (Otomatik Para Makinesi) simülasyonudur. Kullanıcının şifre belirlemesinden başlayarak para yatırma, çekme ve bakiye sorgulama işlemlerini gerçek bir ATM deneyimine yakın biçimde sunar.

Projenin amacı; nesne yönelimli programlama temellerini, kontrol akışı yapılarını ve kullanıcı deneyimi odaklı konsol tasarımını pratikte uygulamaktır.

 Özellikler
Özellik	Açıklama
 Şifre Belirleme	Kullanıcı kendi şifresini oluşturur
 Güvenli Giriş	3 hatalı denemede hesap kilitlenir
 Bakiye Sorgulama	Anlık bakiye görüntüleme
 Para Yatırma	İstenilen tutarda para yatırma
 Para Çekme	Bakiye kontrolü ile güvenli para çekme
 Renkli Arayüz	İşlem türüne göre renk kodlamalı konsol
 Kullanılan Teknolojiler

 
Dil: C# (.NET)
Ortam: .NET Console Application
Yapılar: do-while, while, switch-case, if-else
Özellikler: Console.ForegroundColor, Thread.Sleep, tip dönüşümleri

Geliştirme Fikirleri
 Birden fazla hesap desteği
 İşlem geçmişi / ekstre görüntüleme
 Sınıf tabanlı yeniden yapılandırma (OOP)
 JSON ile basit veri kalıcılığı
 Birim testleri (Unit Tests)
